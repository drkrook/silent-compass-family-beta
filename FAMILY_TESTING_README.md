# Silent Compass — Family Preview

**Working brand only. Trademark and domain clearance are incomplete.**

Tagline: Ready for the Adventure. Prepared for the Unexpected.
Description: Your Offline Survival Companion.

This is the existing GridDown Atlas v1.5 web/PWA prototype with an updated display name and tagline. It is NOT an Android APK, and has NOT been field tested. Existing app features and internal data-storage identifiers are intentionally preserved to reduce the risk of breaking saved data.

## Testing
1. Extract the ZIP and serve its files over HTTPS or localhost. Do not expect full offline features from opening index.html via Android's file manager.
2. On Android, open the HTTPS address in Chrome and use Install app / Add to Home screen.
3. While online, download the desired map tiles and resource data. Switch to airplane mode and test map, markers, GPS, checklists and saved routes.
4. Do not rely on the prototype for life-critical navigation or emergency decisions.

## Not yet implemented / verified
- Native Android APK/AAB packaging and Google Play distribution
- Full encrypted private-location vault (existing private-location exports are unencrypted)
- Complete offline survival video catalog and field guides
- Commercial accounts, subscriptions, purchases and license validation

## Preserve during later updates
Two-finger pinch zoom, marker labels, coordinate input including degree symbols, saved places, tabs and offline cache behavior.
